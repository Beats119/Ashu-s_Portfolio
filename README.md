# Ashish Maurya — Beyond the Model

Interactive portfolio for **Ashish Maurya**, an Applied AI Engineer working across LLMs, RAG, Speech AI, Agentic Systems, Generative AI and research.

## Creative idea

The site is an AI engineer's sketchbook becoming a machine:

BOOT → SEE → RETRIEVE → ACT → SPEAK → GENERATE → VERIFY → RESEARCH → FIELD LOG → STACK → EXPERIMENTS → ORIGIN → SHIP

The experience uses semantic HTML, SVG, Canvas and native browser APIs so the information remains accessible without requiring a WebGL runtime.

## Run locally

Any static server works:

```bash
python -m http.server 8000
```

Open http://localhost:8000/
